# 🏨 Hotel Management Dashboard – Power BI

## 📌 Project Overview
This project focuses on building a **comprehensive Hotel Management Dashboard** using **Power BI**.  
The dashboard provides actionable insights into hotel performance by analyzing **occupancy, revenue, bookings, and room utilization** across different time periods.

It helps hotel managers make **data-driven decisions** related to pricing, inventory management, and revenue optimization.

---

## 🎯 Objective
To develop an interactive Power BI dashboard that allows hotel management to:
- Monitor occupancy trends
- Analyze revenue performance
- Track booking behavior
- Identify patterns across weekly, monthly, and quarterly levels

---

## 🛠 Tools & Technologies
- **Power BI**
- **Excel / CSV (Data Source)**
- **DAX (Measures & Calculations)**

---

## 📊 Key Metrics & Visualizations

### 1️⃣ Occupancy Rate Analysis
- Occupancy rate trends by:
  - Week
  - Month
  - Quarter
- Identifies fluctuations and seasonal patterns

### 2️⃣ Total Occupied Rooms Trend
- Tracks total occupied rooms over time
- Helps optimize room allocation and capacity planning

### 3️⃣ Average Daily Rate (ADR)
- ADR trend analysis by week, month, and quarter
- Supports pricing strategy optimization

### 4️⃣ Revenue Per Available Room (RevPAR)
- Monitors revenue efficiency
- Identifies growth opportunities

### 5️⃣ Total Bookings Trend
- Analyzes booking volume trends
- Helps in demand forecasting

### 6️⃣ Weekend vs Weekday Bookings
- Separate analysis of:
  - Weekend nights
  - Weekday nights
- Enables targeted marketing strategies

### 7️⃣ Cancelled Bookings Analysis
- Tracks cancellation trends over time
- Helps reduce revenue loss

### 8️⃣ Total Revenue Analysis
- Displays total revenue generated
- Used to set and track performance targets

### 9️⃣ Weekday vs Weekend Revenue
- Revenue split between weekday and weekend stays
- Improves pricing decisions

### 🔟 Weekly Revenue Bar Chart
- Weekly total revenue visualization
- Includes:
  - Average revenue line
  - Highlighting above-average and below-average weeks

### 1️⃣1️⃣ Weekly Occupied Rooms Bar Chart
- Weekly occupied rooms comparison
- Includes:
  - Average occupancy reference line
  - Performance highlighting

- Supports revenue growth and operational efficiency
